# Changelog

## 2.0.0 — 2026-11-08

### Changed

- Expanded the skill from studio-inspired design work to complete website creation, reinvention, editing, optimization, maintenance, and management, including use when no studio style is named.
- Made ground-up strategy, information architecture, original copywriting, imagery, functionality, conversion, search, implementation, and operation part of the skill's working scope.
- Treat existing pages, copy, assets, and structure as inputs that may be rethought in broad briefs, while honoring explicit user constraints and protecting data and integration continuity.
- Updated the discovery description and invocation prompt to reflect the broader responsibility; retained automatic skill selection.
- Preserved the foundation of task fit, invention, research, typography, information design, original expression, and proportional execution.

### Added

- A website workflow covering strategy, original content and asset production, complete journeys, conversion measurement, discoverability, migration, launch, and ongoing improvement.
- Four official 2026 project accounts: Kerranova, Arnezi, START, and MPSTATS, with dates, credits, lessons, visual observations, and explicit verification limits.
- A freshness check using official portfolios, news archives, publication dates, and relevant Russian and English sources, scaled to the task and reusable across follow-up edits.
- A source-verification method distinguishing published descriptions, visual observations, tested interactions, and applications to the current brief.
- Russian-source reading guidance and §§190–191, bringing the selected essay guide to twenty-five.
- Review criteria for the proposition, original content and assets, conversion, measurement, discoverability, and operational ownership.

### Fixed

- Removed the implication that a recent review date makes the selected projects current; retained separate dates for the earlier research and this update.
- Distinguished case-study images, mobile mockups, embedded demonstrations, and live client behavior. Visually reviewed all four new case studies; verified Kerranova's embedded tile-shuffle action without claiming production-site or mobile testing.
- Clarified that creative freedom permits rewriting and rebuilding within the brief, while factual claims, commercial commitments, and explicit task boundaries still require grounding.
